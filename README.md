# 烟叶称重系统 - Windows版

## 📋 项目简介

烟叶称重系统是一个基于JavaFX开发的Windows桌面应用程序，用于烟叶收购过程中的称重记录、数据管理和报表导出。

## 🎯 主要功能

- **称重记录**：记录烟农身份信息和烟叶称重数据
- **数据管理**：管理烟农信息和称重历史记录
- **报表导出**：支持Excel格式的数据导出
- **硬件集成**：支持电子秤、打印机、身份证读卡器等硬件设备
- **便携部署**：支持便携式部署，无需安装

## 🛠️ 技术栈

- **开发语言**：Java 17+
- **UI框架**：JavaFX 17.0.2
- **构建工具**：Maven 3.6+
- **数据库**：SQLite（嵌入式）
- **报表生成**：Apache POI（Excel导出）

## 📦 系统要求

### 开发环境
- **Java**：JDK 17或更高版本
- **Maven**：3.6或更高版本
- **操作系统**：Windows 10/11

### 运行环境
- **Java**：JRE 17或更高版本
- **操作系统**：Windows 10/11
- **内存**：建议2GB以上
- **存储**：至少100MB可用空间

## 🚀 快速开始

### 1. 克隆项目
```bash
git clone <repository-url>
cd tobacco_weight_windows
```

### 2. 编译项目
```bash
mvn clean package
```

### 3. 运行程序
```bash
# 方式1：直接运行JAR文件
java -jar target/tobacco-weight-windows-1.0.0.jar

# 方式2：使用Maven插件
mvn javafx:run
```

## 📦 打包部署

### 便携式打包（推荐）

使用提供的批处理脚本生成便携式程序包：

```bash
# 生成便携式程序包
build-portable-simple.bat
```

生成的便携式包包含：
- `tobacco-weight-windows-1.0.0.jar` - 主程序
- `lib/` - JavaFX依赖库
- `启动烟叶称重系统.bat` - 启动脚本
- `使用说明.txt` - 使用说明

### 部署方式

1. **便携式部署**（推荐）
   - 将整个"烟叶称重系统-便携版"文件夹复制到目标机器
   - 确保目标机器安装了Java 17+
   - 双击运行"启动烟叶称重系统.bat"

2. **传统安装**（可选）
   - 使用jpackage生成Windows安装程序
   - 安装到系统目录
   - 通过开始菜单或桌面快捷方式启动

## 🐛 故障排除

### 常见问题

1. **程序无法启动**
   - 检查Java版本是否为17+
   - 确保JavaFX依赖完整
   - 查看错误日志

2. **数据库连接失败**
   - 检查data目录权限
   - 确保磁盘空间充足
   - 重启程序

3. **硬件设备无法识别**
   - 检查设备连接
   - 确认驱动程序安装
   - 查看设备管理器

4. **导出功能异常**
   - 检查exports目录权限
   - 确保Excel文件未被占用
   - 验证文件路径

### 日志查看
程序运行时会生成详细日志：
- **应用程序日志**：`logs/application.log`
- **错误日志**：`logs/error.log`
